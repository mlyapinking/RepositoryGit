# Автопрокат — конфигурация 1С

Конфигурация для учёта проката автомобилей: справочники, документы, регистры, отчёты.

## Структура

Каталог `1c-config/` содержит полную XML-выгрузку конфигурации 1С:Предприятие (формат **2.10**, совместим с учебной платформой **8.3.17**).

### Справочники
- **Автомобили** — марка, модель, гос. номер, год, цвет, КПП, топливо, цена, статус
- **Клиенты** — телефон, адрес, дата рождения, номер ВУ
- **Тарифы** — базовая стоимость, лимит км, стоимость сверх лимита

### Документы
- **ДоговАренды** — оформление договора аренды
- **ФактПроката** — фиксация факта возврата и расчёт суммы

### Перечисления
- ТипКоробкиПередач, ТипТоплива, СтатусыАвтомобиля

### Регистры
- ЦеныПроката, СтатусыАвтомобилей (сведения)
- АрендаОбороты, ВзаиморасчетыСКлиентами (накопления)

## Загрузка в 1С

**Важно:** указывайте папку `1c-config`, а не корень репозитория!

```
RepositoryGit-cursor-.../
├── README.md
├── scripts/
└── 1c-config/          ← ВЫБЕРИТЕ ЭТУ ПАПКУ
    ├── Configuration.xml
    ├── ConfigDumpInfo.xml
    ├── Catalogs/
    └── ...
```

1. Откройте **Конфигуратор**
2. **Конфигурация → Загрузить конфигурацию из файлов...**
3. Укажите папку **`1c-config`** (внутри неё должны быть `Configuration.xml` и `ConfigDumpInfo.xml`)
4. **Конфигурация → Обновить конфигурацию базы данных**

Проверка перед загрузкой:

```bash
python3 scripts/validate_1c_load_path.py
python3 scripts/validate_1c_load_path.py "C:/путь/к/вашей/папке"
```
