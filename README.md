# 1С: Аренда автомобилей — кастомизация

Материалы для учебной конфигурации 1С:Предприятие (аренда автомобилей).

## Содержимое

| Папка / файл | Описание |
|---|---|
| [docs/1C-инструкция.md](docs/1C-инструкция.md) | Полная пошаговая инструкция |
| [code/ДоговАренды_ФормаДокумента.bsl](code/ДоговАренды_ФормаДокумента.bsl) | Автозаполнение цены в договоре аренды |
| [code/ФактПроката_ФормаДокумента.bsl](code/ФактПроката_ФормаДокумента.bsl) | Автозаполнение при закрытии аренды |
| [code/ДоговАренды_МодульОбъекта.bsl](code/ДоговАренды_МодульОбъекта.bsl) | Статус авто «Занят» при проведении договора |
| [code/ФактПроката_МодульОбъекта.bsl](code/ФактПроката_МодульОбъекта.bsl) | Статус авто «Свободен» при закрытии аренды |
| [reports/](reports/) | Три отчёта (запросы СКД + инструкция) |

## Быстрый старт

1. Откройте конфигуратор вашей базы.
2. Следуйте [docs/1C-инструкция.md](docs/1C-инструкция.md).
3. Скопируйте код из папки `code/` в модули форм документов.
4. Создайте отчёты по запросам из папки `reports/`.
5. Обновите конфигурацию БД.
