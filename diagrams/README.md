- `01_use_case.mmd`
- `02_sequence.mmd`
- `03_cooperation.mmd`
- `04_state.mmd`
- `05_er_diagram.mmd`

## Как вставить в Word

1. Вставка → Рисунки → Этот компьютер
2. Выберите нужный PNG
3. Под рисунком подпись: **Рисунок 1.1 — Диаграмма вариантов использования ИС учёта аренды автомобилей**

## Пересоздать PNG (если нужно изменить)

```bash
cd diagrams
npx mmdc -i 01_use_case.mmd -o 01_use_case.png -b white -w 1400
```
