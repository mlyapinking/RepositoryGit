# Настройка базы «Аренда автомобилей» в 1С:Предприятие

Пошаговая инструкция для учебной конфигурации по вашим скриншотам.

---

## 1. Красное кастомное меню в режиме «Предприятие»

У вас интерфейс **«Такси»** (жёлтая панель сверху). Его можно перекрасить и дополнить своей стартовой страницей.

### Вариант А — быстрый: свой стиль (рекомендуется)

1. Откройте **Конфигуратор** → **Конфигурация** → **Общие** → **Стили**.
2. Создайте стиль **КрасныйАренда**.
3. В свойствах стиля задайте цвета (пример «красивого» красного):

| Элемент стиля | Цвет (RGB) | Назначение |
|---|---|---|
| Фон панели навигации | 139, 0, 0 | Тёмно-красный фон верхнего меню |
| Фон активного раздела | 178, 34, 34 | Подсветка выбранного раздела |
| Текст панели навигации | 255, 255, 255 | Белый текст на красном |
| Фон формы | 255, 250, 250 | Светлый фон документов |
| Цвет акцента | 220, 20, 60 | Кнопки «Провести и закрыть» |

4. **Администрирование** → **Параметры** → **Внешний вид** → выберите стиль **КрасныйАренда**.
5. Перезапустите 1С:Предприятие.

### Вариант Б — полностью кастомное меню (стартовая страница)

1. **Общие** → **Общие формы** → создайте **РабочийСтолАренда**.
2. Разместите на форме:
   - **Группа** (горизонтальная) — имитация меню, `ЦветФона = WebЦвета.ТемноКрасный`.
   - **Декорация** с надписью «Аренда автомобилей» (белый шрифт, 18 pt).
   - **Кнопки** или **Гиперссылки**:
     - `Договоры аренды` → `ОткрытьФорму("Документ.ДоговАренды.ФормаСписка")`
     - `Закрытие аренды` → `ОткрытьФорму("Документ.ФактПроката.ФормаСписка")`
     - `Автомобили` → `ОткрытьФорму("Справочник.Автомобили.ФормаСписка")`
     - `Клиенты` → `ОткрытьФорму("Справочник.Клиенты.ФормаСписка")`
3. **Конфигурация** → **Свойства конфигурации** → **Основные** → **Стартовая форма** = `ОбщаяФорма.РабочийСтолАренда`.
4. Обновите конфигурацию БД.

Пример кода кнопки на общей форме:

```bsl
&НаКлиенте
Процедура ОткрытьДоговоры(Команда)
    ОткрытьФорму("Документ.ДоговАренды.ФормаСписка");
КонецПроцедуры
```

### Вариант В — иконки разделов

1. **Подсистемы** → для каждой (Главное, Аренда, Справочники) загрузите свою картинку (PNG 32×32, красная тематика).
2. В **Командном интерфейсе** подсистемы настройте порядок и видимость команд.

## 2. Автозаполнение «Цена за сутки» в документе «Догов аренды»

### Шаг 1 — обработчик на форме

1. Конфигуратор → **Документы** → **ДоговАренды** → **Формы** → **ФормаДокумента**.
2. Выделите реквизит **Автомобиль** → вкладка **События** → **ПриИзменении** → создайте обработчик.
3. Вставьте код из файла `code/ДоговАренды_ФормаДокумента.bsl`.

### Шаг 2 — при открытии существующего договора

На форме документа добавьте в **ПриСозданииНаСервере** вызов той же процедуры заполнения, если автомобиль уже выбран.

### Логика

При выборе автомобиля система читает `Справочник.Автомобили.ЦенаЗаСутки` и записывает в `Объект.ЦенаЗаСутки`.

---

## 3. Автозаполнение при «Закрытии аренды» (ФактПроката)

1. **Документы** → **ФактПроката** → **ФормаДокумента**.
2. Реквизит **Договор** → **ПриИзменении** → создайте обработчик (1С сама добавит пустую процедуру).
3. То же для **ДатаВозврата** и **ДопРасходы**.
4. **Не вставляйте код целиком!** В уже созданные процедуры добавьте вызовы, а серверные процедуры — отдельно.

> **Ошибка «уже определена (ДопРасходыПриИзменении)»** — значит процедура продублирована. Удалите вторую копию и оставьте одну.

### Логика

При выборе договора:
- берётся **ЦенаЗаСутки** из договора (зафиксированная на момент аренды);
- пересчитываются **КоличествоСуток** и **ИтоговаяСумма**.

Формула итога: `КоличествоСуток × ЦенаЗаСутки + ДопРасходы`.

Также добавьте обработчики **ПриИзменении** для полей **ДатаВозврата**, **ДопРасходы** — чтобы сумма пересчитывалась автоматически.

## 4. Три отчёта

Создайте отчёты через **Схему компоновки данных (СКД)**. Запросы — в папке `reports/`.

| № | Отчёт | Файл запроса | Назначение |
|---|---|---|---|
| 1 | **Автопарк и загрузка** | `ОтчетАвтопарк.txt` | Список авто, цена, статус, сколько раз сдавались |
| 2 | **Доходы по аренде** | `ОтчетДоходыПоАренде.txt` | Суммы по закрытым арендам за период |
| 3 | **История аренд клиента** | `ОтчетИсторияКлиента.txt` | Договоры и закрытия по выбранному клиенту |

### Как создать отчёт в конфигураторе

1. **Отчёты** → **Добавить** → имя, например `ОтчетАвтопарк`.
2. Основная схема → **Конструктор схемы компоновки данных**.
3. **Набор данных** → **Запрос** → вставьте текст из соответствующего файла.
4. **Ресурсы** — поля с агрегатами (Сумма, Количество).
5. **Настройки** → **Структура**: группировки + детальные записи.
6. Создайте **Форму отчёта** (автоматически).
7. Добавьте отчёт в подсистему **Аренда** → **Отчеты**.

Подробные шаги по каждому отчёту — в `reports/README.md`.

---

## 5. Порядок внедрения

1. Сохраните конфигурацию, сделайте резервную копию БД.
2. Стиль / стартовая форма (меню).
3. Код форм документов (автозаполнение цены).
4. Три отчёта.
5. **Конфигурация** → **Обновить конфигурацию базы данных**.
6. Проверьте в 1С:Предприятие.
