# Доработки конфигурации 1С для базы проката автомобилей

В репозитории нет выгрузки конфигурации 1С, поэтому ниже приведены готовые изменения, которые нужно внести в Конфигураторе. Названия объектов взяты со скриншотов:

- справочник `Автомобили`;
- справочник `Клиенты`;
- документ `ДоговорАренды`;
- документ `ФактПроката` / форма с названием "Закрытие аренды".

## 1. Красное кастомное меню в режиме 1С:Предприятие

Стандартную верхнюю панель 1С полностью перекрасить штатными свойствами обычно нельзя: ее внешний вид задает платформа. Практичный вариант для учебной конфигурации - сделать свою начальную форму с красными кнопками-разделами и открывать ее при запуске.

### 1.1. Создайте общую форму

В Конфигураторе:

1. Откройте `Общие` -> `Общие формы`.
2. Создайте форму `ГлавноеМенюАренды`.
3. Добавьте на форму группу с крупными кнопками:
   - `Автомобили`;
   - `Клиенты`;
   - `Договоры аренды`;
   - `Закрытие аренды`;
   - `Цены проката`;
   - `Отчеты`.
4. Для группы и декоративных надписей задайте красную цветовую схему:
   - фон: темно-красный или бордовый;
   - текст: белый;
   - акцентные кнопки: красный/светло-красный.

Если у кнопки в вашей версии платформы нет свойства цвета фона, используйте декоративные панели/надписи с красным фоном, а сами команды разместите внутри них.

### 1.2. Команды формы `ГлавноеМенюАренды`

В модуль общей формы добавьте обработчики команд:

```bsl
&НаКлиенте
Процедура ОткрытьАвтомобили(Команда)
    ОткрытьФорму("Справочник.Автомобили.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьКлиенты(Команда)
    ОткрытьФорму("Справочник.Клиенты.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьДоговорыАренды(Команда)
    ОткрытьФорму("Документ.ДоговорАренды.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьЗакрытиеАренды(Команда)
    ОткрытьФорму("Документ.ФактПроката.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьЦеныПроката(Команда)
    ОткрытьФорму("Справочник.Автомобили.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьОтчеты(Команда)
    ОткрытьФорму("Отчет.ДоходПоАрендам.ФормаОтчета");
КонецПроцедуры
```

> Если у вас есть отдельный справочник `ЦеныПроката`, замените строку для цен на `ОткрытьФорму("Справочник.ЦеныПроката.ФормаСписка");`.

### 1.3. Открытие меню при запуске

В модуль управляемого приложения добавьте:

```bsl
&НаКлиенте
Процедура ПриНачалеРаботыСистемы()
    ОткрытьФорму("ОбщаяФорма.ГлавноеМенюАренды");
КонецПроцедуры
```

Чтобы пользователь видел именно кастомное меню, уберите лишние команды из стандартного командного интерфейса подсистем или оставьте стандартные разделы как запасную навигацию.

## 2. Автозаполнение цены за сутки в документе `ДоговорАренды`

Нужно, чтобы при выборе автомобиля в договоре поле `ЦенаЗаСутки` автоматически брало значение из справочника `Автомобили`.

### 2.1. Форма документа `ДоговорАренды`

Откройте форму документа `ДоговорАренды`. Для поля `Автомобиль` назначьте событие `ПриИзменении` и вставьте в модуль формы:

```bsl
&НаКлиенте
Процедура АвтомобильПриИзменении(Элемент)
    ЗаполнитьЦенуЗаСуткиПоАвтомобилю();
КонецПроцедуры

&НаКлиенте
Процедура ЗаполнитьЦенуЗаСуткиПоАвтомобилю()
    Если ЗначениеЗаполнено(Объект.Автомобиль) Тогда
        Объект.ЦенаЗаСутки = ПолучитьЦенуЗаСуткиАвтомобиля(Объект.Автомобиль);
    Иначе
        Объект.ЦенаЗаСутки = 0;
    КонецЕсли;
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьЦенуЗаСуткиАвтомобиля(Автомобиль)
    Если Не ЗначениеЗаполнено(Автомобиль) Тогда
        Возврат 0;
    КонецЕсли;

    Возврат Автомобиль.ЦенаЗаСутки;
КонецФункции
```

### 2.2. Модуль объекта `ДоговорАренды`

Чтобы цена не потерялась при записи документа через другие формы или обработку, добавьте контроль в модуль объекта:

```bsl
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
    Если ЗначениеЗаполнено(Автомобиль) И ЦенаЗаСутки = 0 Тогда
        ЦенаЗаСутки = Автомобиль.ЦенаЗаСутки;
    КонецЕсли;
КонецПроцедуры
```

## 3. Автозаполнение цены за сутки в документе `ФактПроката` / "Закрытие аренды"

На форме закрытия аренды цена должна подтягиваться по выбранному договору из автомобиля, который указан в договоре.

### 3.1. Форма документа `ФактПроката`

Для поля `Договор` назначьте событие `ПриИзменении`. В модуль формы добавьте:

```bsl
&НаКлиенте
Процедура ДоговорПриИзменении(Элемент)
    ЗаполнитьДанныеПоДоговору();
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура ДатаВозвратаПриИзменении(Элемент)
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура ДопРасходыПриИзменении(Элемент)
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура КоличествоСутокПриИзменении(Элемент)
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура ЗаполнитьДанныеПоДоговору()
    Если Не ЗначениеЗаполнено(Объект.Договор) Тогда
        Объект.ЦенаЗаСутки = 0;
        Объект.КоличествоСуток = 0;
        Возврат;
    КонецЕсли;

    ДанныеДоговора = ПолучитьДанныеДоговора(Объект.Договор);
    Объект.ЦенаЗаСутки = ДанныеДоговора.ЦенаЗаСутки;

    Если Не ЗначениеЗаполнено(Объект.ДатаВозврата) И ЗначениеЗаполнено(ДанныеДоговора.ДатаОкончания) Тогда
        Объект.ДатаВозврата = ДанныеДоговора.ДатаОкончания;
    КонецЕсли;

    Если ЗначениеЗаполнено(ДанныеДоговора.ДатаНачала) И ЗначениеЗаполнено(Объект.ДатаВозврата) Тогда
        Объект.КоличествоСуток = РассчитатьКоличествоСуток(ДанныеДоговора.ДатаНачала, Объект.ДатаВозврата);
    КонецЕсли;
КонецПроцедуры

&НаКлиенте
Процедура ПересчитатьИтоговуюСумму()
    Объект.ИтоговаяСумма = Объект.КоличествоСуток * Объект.ЦенаЗаСутки + Объект.ДопРасходы;
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьДанныеДоговора(Договор)
    Данные = Новый Структура;
    Данные.Вставить("ЦенаЗаСутки", 0);
    Данные.Вставить("ДатаНачала", Неопределено);
    Данные.Вставить("ДатаОкончания", Неопределено);

    Если Не ЗначениеЗаполнено(Договор) Тогда
        Возврат Данные;
    КонецЕсли;

    ОбъектДоговора = Договор.ПолучитьОбъект();
    Данные.ДатаНачала = ОбъектДоговора.ДатаНачала;
    Данные.ДатаОкончания = ОбъектДоговора.ДатаОкончания;

    Если ЗначениеЗаполнено(ОбъектДоговора.Автомобиль) Тогда
        Данные.ЦенаЗаСутки = ОбъектДоговора.Автомобиль.ЦенаЗаСутки;
    Иначе
        Данные.ЦенаЗаСутки = ОбъектДоговора.ЦенаЗаСутки;
    КонецЕсли;

    Возврат Данные;
КонецФункции

&НаСервереБезКонтекста
Функция РассчитатьКоличествоСуток(ДатаНачала, ДатаВозврата)
    КоличествоСуток = Цел((НачалоДня(ДатаВозврата) - НачалоДня(ДатаНачала)) / 86400) + 1;

    Если КоличествоСуток < 1 Тогда
        КоличествоСуток = 1;
    КонецЕсли;

    Возврат КоличествоСуток;
КонецФункции
```

### 3.2. Модуль объекта `ФактПроката`

Добавьте страховку перед записью:

```bsl
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
    Если ЗначениеЗаполнено(Договор) Тогда
        ОбъектДоговора = Договор.ПолучитьОбъект();

        Если ЦенаЗаСутки = 0 Тогда
            Если ЗначениеЗаполнено(ОбъектДоговора.Автомобиль) Тогда
                ЦенаЗаСутки = ОбъектДоговора.Автомобиль.ЦенаЗаСутки;
            Иначе
                ЦенаЗаСутки = ОбъектДоговора.ЦенаЗаСутки;
            КонецЕсли;
        КонецЕсли;

        Если КоличествоСуток = 0
            И ЗначениеЗаполнено(ОбъектДоговора.ДатаНачала)
            И ЗначениеЗаполнено(ДатаВозврата) Тогда

            КоличествоСуток = Цел((НачалоДня(ДатаВозврата) - НачалоДня(ОбъектДоговора.ДатаНачала)) / 86400) + 1;

            Если КоличествоСуток < 1 Тогда
                КоличествоСуток = 1;
            КонецЕсли;
        КонецЕсли;
    КонецЕсли;

    ИтоговаяСумма = КоличествоСуток * ЦенаЗаСутки + ДопРасходы;
КонецПроцедуры
```

## 4. Три отчета для базы

Все отчеты лучше делать через СКД:

1. Создайте объект `Отчет`.
2. Откройте `Основная схема компоновки данных`.
3. Добавьте набор данных `Запрос`.
4. Вставьте запрос из соответствующего раздела ниже.
5. На вкладке `Настройки` добавьте поля, группировки и итоги.

### 4.1. Отчет `АктивныеДоговорыАренды`

Показывает проведенные договоры, по которым еще нет проведенного закрытия аренды.

```bsl
ВЫБРАТЬ
    Договор.Ссылка КАК Договор,
    Договор.Дата КАК ДатаДоговора,
    Договор.Клиент КАК Клиент,
    Договор.Автомобиль КАК Автомобиль,
    Договор.ДатаНачала КАК ДатаНачала,
    Договор.ДатаОкончания КАК ДатаОкончания,
    Договор.ЦенаЗаСутки КАК ЦенаЗаСутки,
    Договор.СуммаЗалога КАК СуммаЗалога
ИЗ
    Документ.ДоговорАренды КАК Договор
        ЛЕВОЕ СОЕДИНЕНИЕ Документ.ФактПроката КАК Факт
        ПО Факт.Договор = Договор.Ссылка
            И Факт.Проведен
ГДЕ
    Договор.Проведен
    И Факт.Ссылка ЕСТЬ NULL
```

Рекомендуемые настройки СКД:

- группировка: `Клиент`;
- поля: `Договор`, `Автомобиль`, `ДатаНачала`, `ДатаОкончания`, `ЦенаЗаСутки`, `СуммаЗалога`;
- итог: сумма по `СуммаЗалога`.

### 4.2. Отчет `ДоходПоАрендам`

Показывает закрытые аренды и выручку за выбранный период.

Параметры СКД:

- `ДатаНачала`, тип `Дата`;
- `ДатаОкончания`, тип `Дата`.

```bsl
ВЫБРАТЬ
    Факт.Дата КАК ДатаЗакрытия,
    Факт.Договор КАК Договор,
    Факт.Договор.Клиент КАК Клиент,
    Факт.Договор.Автомобиль КАК Автомобиль,
    Факт.КоличествоСуток КАК КоличествоСуток,
    Факт.ЦенаЗаСутки КАК ЦенаЗаСутки,
    Факт.ДопРасходы КАК ДопРасходы,
    Факт.ИтоговаяСумма КАК ИтоговаяСумма
ИЗ
    Документ.ФактПроката КАК Факт
ГДЕ
    Факт.Проведен
    И Факт.Дата МЕЖДУ &ДатаНачала И &ДатаОкончания
```

Рекомендуемые настройки СКД:

- группировка: `Клиент`;
- вложенная группировка: `Автомобиль`;
- итог: сумма по `ИтоговаяСумма`, `ДопРасходы`, `КоличествоСуток`.

### 4.3. Отчет `ЗагрузкаАвтомобилей`

Показывает, какие автомобили чаще сдавались и сколько денег принесли.

Параметры СКД:

- `ДатаНачала`, тип `Дата`;
- `ДатаОкончания`, тип `Дата`.

```bsl
ВЫБРАТЬ
    Автомобили.Ссылка КАК Автомобиль,
    Автомобили.ГосНомер КАК ГосНомер,
    Автомобили.Марка КАК Марка,
    Автомобили.Модель КАК Модель,
    Автомобили.Статус КАК Статус,
    КОЛИЧЕСТВО(Факт.Ссылка) КАК КоличествоАренд,
    СУММА(ЕСТЬNULL(Факт.КоличествоСуток, 0)) КАК КоличествоСуток,
    СУММА(ЕСТЬNULL(Факт.ИтоговаяСумма, 0)) КАК Выручка
ИЗ
    Справочник.Автомобили КАК Автомобили
        ЛЕВОЕ СОЕДИНЕНИЕ Документ.ФактПроката КАК Факт
        ПО Факт.Договор.Автомобиль = Автомобили.Ссылка
            И Факт.Проведен
            И Факт.Дата МЕЖДУ &ДатаНачала И &ДатаОкончания

СГРУППИРОВАТЬ ПО
    Автомобили.Ссылка,
    Автомобили.ГосНомер,
    Автомобили.Марка,
    Автомобили.Модель,
    Автомобили.Статус

УПОРЯДОЧИТЬ ПО
    Выручка УБЫВ
```

Рекомендуемые настройки СКД:

- группировка: `Автомобиль`;
- поля: `ГосНомер`, `Марка`, `Модель`, `Статус`, `КоличествоАренд`, `КоличествоСуток`, `Выручка`;
- итоги: сумма по `КоличествоАренд`, `КоличествоСуток`, `Выручка`.

## 5. Проверка после внесения изменений

1. Обновите конфигурацию базы данных.
2. Запустите `1С:Предприятие`.
3. Откройте документ `Договор аренды`.
4. Выберите автомобиль - поле `Цена за сутки` должно заполниться автоматически.
5. Откройте документ `Закрытие аренды`.
6. Выберите договор - цена за сутки, количество суток и итоговая сумма должны заполниться автоматически.
7. Откройте каждый из трех отчетов и сформируйте их за период, где есть проведенные документы.
