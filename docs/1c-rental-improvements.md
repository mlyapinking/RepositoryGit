# Доработки базы 1C для проката автомобилей

Ниже описано, как доработать вашу конфигурацию 1C:Предприятие по скриншотам:

1. сделать кастомное красное меню в режиме предприятия;
2. автоматически подставлять цену автомобиля за сутки в документе `ДоговорАренды`;
3. автоматически подставлять цену за сутки и пересчитывать сумму в документе `ФактПроката`;
4. добавить 3 отчета для базы.

В репозитории нет выгрузки конфигурации 1C (`.cf`, `.dt`, `.xml`, EDT-проект), поэтому изменения нельзя применить к базе автоматически. Все ниже можно перенести вручную через Конфигуратор.

## 1. Кастомное красное меню в режиме предприятия

Стандартное верхнее меню 1C полностью перекрасить средствами платформы обычно нельзя. Практичный вариант - сделать свою общую форму `ГлавноеМеню` с красными кнопками и открывать ее при входе в систему.

### 1.1. Создайте общую форму

В Конфигураторе:

1. Откройте `Общие` -> `Общие формы`.
2. Создайте форму `ГлавноеМеню`.
3. Добавьте группу `ГруппаМеню`.
4. В группе разместите крупные кнопки:
   - `Договоры аренды`;
   - `Закрытие аренды`;
   - `Автомобили`;
   - `Клиенты`;
   - `Тарифы`;
   - `Цены проката`;
   - `Отчеты`.
5. Для группы и кнопок задайте красное оформление:
   - фон группы: темно-красный;
   - фон кнопок: красный или бордовый;
   - цвет текста: белый;
   - шрифт: жирный, 12-14;
   - высота кнопок: 40-50.

Если свойство цвета у кнопок недоступно в вашей версии платформы, используйте декоративные надписи/картинки как плитки меню и команды рядом с ними.

### 1.2. Модуль общей формы `ГлавноеМеню`

В модуль формы добавьте команды открытия списков:

```bsl
&НаКлиенте
Процедура ОткрытьДоговорыАренды(Команда)
    ОткрытьФорму("Документ.ДоговорАренды.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьЗакрытиеАренды(Команда)
    ОткрытьФорму("Документ.ФактПроката.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьАвтомобили(Команда)
    ОткрытьФорму("Справочник.Автомобили.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьКлиенты(Команда)
    ОткрытьФорму("Справочник.Клиенты.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьТарифы(Команда)
    ОткрытьФорму("Справочник.Тарифы.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьЦеныПроката(Команда)
    ОткрытьФорму("Документ.ЦеныПроката.ФормаСписка");
КонецПроцедуры

&НаКлиенте
Процедура ОткрытьОтчеты(Команда)
    ОткрытьФорму("ОбщаяФорма.МенюОтчетов");
КонецПроцедуры
```

Если объектов `Справочник.Тарифы`, `Документ.ЦеныПроката` или `ОбщаяФорма.МенюОтчетов` у вас нет, замените имена форм на реальные объекты конфигурации.

### 1.3. Открывать меню при старте

В модуле управляемого приложения добавьте:

```bsl
&НаКлиенте
Процедура ПриНачалеРаботыСистемы()
    ОткрытьФорму("ОбщаяФорма.ГлавноеМеню");
КонецПроцедуры
```

Чтобы стандартные разделы не мешали, можно:

- убрать лишние подсистемы из командного интерфейса;
- оставить только нужные разделы;
- сделать `ГлавноеМеню` стартовой формой пользователя.

## 2. Автоподстановка цены в `ДоговорАренды`

На третьем скриншоте в документе `ДоговорАренды` есть реквизиты:

- `Клиент`;
- `Автомобиль`;
- `ЦенаЗаСутки`;
- `ДатаНачала`;
- `ДатаОкончания`;
- `СуммаЗалога`.

Нужно, чтобы после выбора автомобиля цена бралась из справочника `Автомобили.ЦенаЗаСутки`.

### 2.1. Обработчик формы документа

Откройте:

`Документы` -> `ДоговорАренды` -> `Формы` -> форма документа -> модуль формы.

Добавьте код:

```bsl
&НаКлиенте
Процедура АвтомобильПриИзменении(Элемент)
    Объект.ЦенаЗаСутки = ПолучитьЦенуАвтомобиля(Объект.Автомобиль);
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьЦенуАвтомобиля(Автомобиль)

    Если Не ЗначениеЗаполнено(Автомобиль) Тогда
        Возврат 0;
    КонецЕсли;

    Возврат Автомобиль.ЦенаЗаСутки;

КонецФункции
```

После этого в свойствах поля формы `Автомобиль` установите событие `ПриИзменении` = `АвтомобильПриИзменении`.

### 2.2. Заполнение при открытии существующего документа

Если в старых документах автомобиль выбран, а цена пустая, можно дозаполнить цену при открытии формы:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

    Если ЗначениеЗаполнено(Объект.Автомобиль)
        И Объект.ЦенаЗаСутки = 0 Тогда
        Объект.ЦенаЗаСутки = Объект.Автомобиль.ЦенаЗаСутки;
    КонецЕсли;

КонецПроцедуры
```

## 3. Автоподстановка цены и расчет в `ФактПроката`

На четвертом скриншоте документ закрытия аренды называется `ФактПроката`, а в интерфейсе - `Закрытие аренды`.

Реквизиты:

- `Договор`;
- `ДатаВозврата`;
- `ПробегФакт`;
- `ДопРасходы`;
- `КоличествоСуток`;
- `ЦенаЗаСутки`;
- `ИтоговаяСумма`.

Цена должна подтягиваться из справочника автомобиля договора:

`ФактПроката.Договор -> ДоговорАренды.Автомобиль -> Автомобили.ЦенаЗаСутки`.

### 3.1. Модуль формы `ФактПроката`

Откройте:

`Документы` -> `ФактПроката` -> `Формы` -> форма документа -> модуль формы.

Добавьте:

```bsl
&НаКлиенте
Процедура ДоговорПриИзменении(Элемент)
    ЗаполнитьЦенуИДатыПоДоговору();
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура ДатаВозвратаПриИзменении(Элемент)
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура ДопРасходыПриИзменении(Элемент)
    ПересчитатьИтоговуюСумму();
КонецПроцедуры

&НаКлиенте
Процедура ЗаполнитьЦенуИДатыПоДоговору()

    ДанныеДоговора = ПолучитьДанныеДоговора(Объект.Договор);

    Объект.ЦенаЗаСутки = ДанныеДоговора.ЦенаЗаСутки;

    Если Не ЗначениеЗаполнено(Объект.ДатаВозврата)
        И ЗначениеЗаполнено(ДанныеДоговора.ДатаОкончания) Тогда
        Объект.ДатаВозврата = ДанныеДоговора.ДатаОкончания;
    КонецЕсли;

КонецПроцедуры

&НаКлиенте
Процедура ПересчитатьИтоговуюСумму()

    ДанныеДоговора = ПолучитьДанныеДоговора(Объект.Договор);

    Если ЗначениеЗаполнено(ДанныеДоговора.ДатаНачала)
        И ЗначениеЗаполнено(Объект.ДатаВозврата) Тогда
        Объект.КоличествоСуток = РассчитатьКоличествоСуток(
            ДанныеДоговора.ДатаНачала,
            Объект.ДатаВозврата);
    Иначе
        Объект.КоличествоСуток = 0;
    КонецЕсли;

    Объект.ИтоговаяСумма =
        Объект.КоличествоСуток * Объект.ЦенаЗаСутки
        + Объект.ДопРасходы;

КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьДанныеДоговора(Договор)

    Данные = Новый Структура(
        "ДатаНачала,ДатаОкончания,ЦенаЗаСутки",
        Неопределено,
        Неопределено,
        0);

    Если Не ЗначениеЗаполнено(Договор) Тогда
        Возврат Данные;
    КонецЕсли;

    Данные.ДатаНачала = Договор.ДатаНачала;
    Данные.ДатаОкончания = Договор.ДатаОкончания;

    Если ЗначениеЗаполнено(Договор.Автомобиль) Тогда
        Данные.ЦенаЗаСутки = Договор.Автомобиль.ЦенаЗаСутки;
    Иначе
        Данные.ЦенаЗаСутки = Договор.ЦенаЗаСутки;
    КонецЕсли;

    Возврат Данные;

КонецФункции

&НаСервереБезКонтекста
Функция РассчитатьКоличествоСуток(ДатаНачала, ДатаВозврата)

    Если Не ЗначениеЗаполнено(ДатаНачала)
        Или Не ЗначениеЗаполнено(ДатаВозврата) Тогда
        Возврат 0;
    КонецЕсли;

    КоличествоСуток = Цел(
        (НачалоДня(ДатаВозврата) - НачалоДня(ДатаНачала)) / 86400) + 1;

    Если КоличествоСуток < 1 Тогда
        КоличествоСуток = 1;
    КонецЕсли;

    Возврат КоличествоСуток;

КонецФункции
```

Назначьте события формы:

- поле `Договор`: `ПриИзменении` = `ДоговорПриИзменении`;
- поле `ДатаВозврата`: `ПриИзменении` = `ДатаВозвратаПриИзменении`;
- поле `ДопРасходы`: `ПриИзменении` = `ДопРасходыПриИзменении`.

### 3.2. Контроль при проведении

Чтобы цена была заполнена даже при записи через обработку или импорт, добавьте проверку в модуль объекта документа `ФактПроката`:

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)

    Если ЗначениеЗаполнено(Договор)
        И ЗначениеЗаполнено(Договор.Автомобиль) Тогда
        ЦенаЗаСутки = Договор.Автомобиль.ЦенаЗаСутки;
    КонецЕсли;

    Если КоличествоСуток = 0
        И ЗначениеЗаполнено(Договор)
        И ЗначениеЗаполнено(ДатаВозврата) Тогда
        КоличествоСуток = Цел(
            (НачалоДня(ДатаВозврата) - НачалоДня(Договор.ДатаНачала)) / 86400) + 1;
    КонецЕсли;

    ИтоговаяСумма = КоличествоСуток * ЦенаЗаСутки + ДопРасходы;

КонецПроцедуры
```

Если в вашем документе уже есть своя `ОбработкаПроведения`, не заменяйте ее полностью - вставьте только эти строки в начало или перед движениями.

## 4. Три отчета для базы

Отчеты удобнее сделать через СКД:

`Отчеты` -> `Создать` -> `Схема компоновки данных` -> `Наборы данных` -> `Запрос`.

### Отчет 1. `СвободныеАвтомобили`

Назначение: показать автомобили, которые сейчас доступны для аренды.

Поля:

- автомобиль;
- госномер;
- марка;
- модель;
- цвет;
- тип топлива;
- цена за сутки;
- статус.

Запрос:

```bsl
ВЫБРАТЬ
    Автомобили.Ссылка КАК Автомобиль,
    Автомобили.ГосНомер КАК ГосНомер,
    Автомобили.Марка КАК Марка,
    Автомобили.Модель КАК Модель,
    Автомобили.Цвет КАК Цвет,
    Автомобили.ТипТоплива КАК ТипТоплива,
    Автомобили.ЦенаЗаСутки КАК ЦенаЗаСутки,
    Автомобили.Статус КАК Статус
ИЗ
    Справочник.Автомобили КАК Автомобили
ГДЕ
    Автомобили.Статус = &СтатусСвободен
УПОРЯДОЧИТЬ ПО
    Автомобили.Марка,
    Автомобили.Модель
```

Параметр `СтатусСвободен` заполните значением вашего перечисления/справочника статусов, например `Свободен`. Если статус у вас хранится строкой, можно заменить условие на:

```bsl
Автомобили.Статус = "Свободен"
```

### Отчет 2. `ДоговорыАрендыЗаПериод`

Назначение: видеть все оформленные договоры за выбранный период.

Параметры:

- `ДатаНачалаПериода`;
- `ДатаОкончанияПериода`.

Запрос:

```bsl
ВЫБРАТЬ
    Договоры.Ссылка КАК Договор,
    Договоры.Дата КАК ДатаДокумента,
    Договоры.Клиент КАК Клиент,
    Договоры.Автомобиль КАК Автомобиль,
    Договоры.ДатаНачала КАК ДатаНачала,
    Договоры.ДатаОкончания КАК ДатаОкончания,
    Договоры.ЦенаЗаСутки КАК ЦенаЗаСутки,
    Договоры.СуммаЗалога КАК СуммаЗалога
ИЗ
    Документ.ДоговорАренды КАК Договоры
ГДЕ
    Договоры.Дата МЕЖДУ &ДатаНачалаПериода И &ДатаОкончанияПериода
    И Договоры.Проведен
УПОРЯДОЧИТЬ ПО
    Договоры.Дата
```

В настройках СКД добавьте отбор по клиенту и автомобилю, если нужно быстро искать историю по конкретному клиенту или машине.

### Отчет 3. `ВыручкаПоАвтомобилям`

Назначение: посчитать доход по закрытым арендам.

Параметры:

- `ДатаНачалаПериода`;
- `ДатаОкончанияПериода`.

Запрос:

```bsl
ВЫБРАТЬ
    ФактПроката.Договор.Автомобиль КАК Автомобиль,
    КОЛИЧЕСТВО(ФактПроката.Ссылка) КАК КоличествоЗакрытий,
    СУММА(ФактПроката.КоличествоСуток) КАК ВсегоСуток,
    СУММА(ФактПроката.ДопРасходы) КАК ДопРасходы,
    СУММА(ФактПроката.ИтоговаяСумма) КАК Выручка
ИЗ
    Документ.ФактПроката КАК ФактПроката
ГДЕ
    ФактПроката.Дата МЕЖДУ &ДатаНачалаПериода И &ДатаОкончанияПериода
    И ФактПроката.Проведен
СГРУППИРОВАТЬ ПО
    ФактПроката.Договор.Автомобиль
УПОРЯДОЧИТЬ ПО
    Выручка УБЫВ
```

В ресурсах СКД установите:

- `КоличествоЗакрытий` - сумма;
- `ВсегоСуток` - сумма;
- `ДопРасходы` - сумма;
- `Выручка` - сумма.

## 5. Проверка после доработки

Проверьте сценарии:

1. Открыть режим предприятия - должна появиться красная форма меню.
2. Создать `ДоговорАренды`, выбрать автомобиль - `ЦенаЗаСутки` должна заполниться автоматически.
3. Создать `ФактПроката`, выбрать договор - `ЦенаЗаСутки` должна взяться из автомобиля договора.
4. Изменить `ДатаВозврата` или `ДопРасходы` - `КоличествоСуток` и `ИтоговаяСумма` должны пересчитаться.
5. Провести документы.
6. Открыть 3 отчета и проверить данные за период.

## 6. Что нужно прислать, если хотите автоматическое внесение в базу

Чтобы эти изменения можно было применить напрямую в репозитории, выгрузите конфигурацию одним из способов:

- файл `.cf`;
- файл `.dt`;
- XML-выгрузка конфигурации;
- проект 1C:EDT.

Лучше всего для Git - XML-выгрузка или EDT-проект, потому что их можно редактировать и проверять в pull request.
