# Отчёты для базы «Аренда автомобилей»

## Общий алгоритм создания отчёта в конфигураторе

1. **Отчёты** → ПКМ → **Добавить**.
2. Имя: `ОтчетАвтопарк` (или другое из таблицы ниже).
3. **Основная схема компоновки данных** → открыть конструктор СКД.
4. **Наборы данных** → **Добавить** → **Запрос**.
5. Скопируйте текст запроса из соответствующего `.txt` файла.
6. Нажмите **Запрос** → **Конструктор** — проверьте, что поля подтянулись.
7. На вкладке **Ресурсы** отметьте поля с агрегатами (Сумма, Количество).
8. **Настройки** → **Структура отчёта** — добавьте группировки (см. ниже).
9. Сохраните схему, создайте **Форму отчёта**.
10. Добавьте отчёт в подсистему **Аренда** (раздел «Отчёты»).

---

## Отчёт 1: Автопарк и загрузка (`ОтчетАвтопарк`)

**Файл запроса:** `ОтчетАвтопарк.txt`

**Параметры:** нет (или период — по желанию).

**Структура СКД:**
- Детальные записи: Автомобиль, Марка, Модель, ГосНомер, ЦенаЗаСутки, Статус, КоличествоАренд.

**Итоги:** сумма по `КоличествоАренд`.

**Назначение:** видеть весь автопарк, цены и сколько раз каждый автомобиль сдавался в аренду.

---

## Отчёт 2: Доходы по аренде (`ОтчетДоходыПоАренде`)

**Файл запроса:** `ОтчетДоходыПоАренде.txt`

**Параметры СКД:**
| Имя | Тип | Заголовок |
|---|---|---|
| ДатаНачала | Дата | Дата начала |
| ДатаОкончания | Дата | Дата окончания |

Значения по умолчанию: начало и конец текущего месяца.

**Структура СКД:**
1. Группировка: **Автомобиль**
2. Детальные записи: НомерЗакрытия, Дата, Клиент, КоличествоСуток, ЦенаЗаСутки, ДопРасходы, ИтоговаяСумма

**Итоги:** Сумма(ИтоговаяСумма), Сумма(КоличествоСуток).

**Назначение:** финансовый отчёт по закрытым арендам за период.

---

## Отчёт 3: История аренд клиента (`ОтчетИсторияКлиента`)

**Файл запроса:** `ОтчетИсторияКлиента.txt`

**Параметры СКД:**
| Имя | Тип | Заголовок |
|---|---|---|
| Клиент | СправочникСсылка.Клиенты | Клиент |

**Структура СКД:**
- Детальные записи: все поля запроса.

**Итоги:** Сумма(ИтоговаяСумма), Количество(НомерДоговора).

**Назначение:** полная история аренд выбранного клиента — договоры и закрытия.

---

## Размещение в интерфейсе

1. **Подсистемы** → **Аренда** → **Состав** → добавьте все три отчёта.
2. В командном интерфейсе подсистемы «Аренда» они появятся в выпадающем меню **Отчёты** (как на вашем скриншоте).

---

## Если документ называется иначе

По скриншоту метаданных:
- Документ договора: `ДоговАренды`
- Документ закрытия: `ФактПроката`

Если в вашей базе имена отличаются — замените их в текстах запросов.
