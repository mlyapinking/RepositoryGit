# Отчёты пустые — как исправить

## Главные причины пустого экрана

| Причина | Как проверить | Решение |
|---|---|---|
| **Не выбран клиент** | Отчёт «История клиента» | Нажмите **Настройки...** → выберите клиента → **Сформировать** |
| **Неверный период** | Отчёт «Доходы» | В настройках укажите период, куда попадают ваши документы (например 01.05.2026–31.05.2026) |
| **Не настроена структура СКД** | Любой отчёт | В схеме должны быть **Детальные записи** + выбранные поля (см. ниже) |
| **Документы не проведены** | Любой отчёт | Договоры и закрытия должны быть **проведены** (зелёная галочка) |

---

## Отчёт «История клиента» — что сделать прямо сейчас

1. Откройте отчёт.
2. Нажмите **Настройки...** (не «Сформировать» сразу!).
3. Вкладка **Отбор** или **Параметры** → поле **Клиент** → выберите, например, `Антонов Антон Антонович`.
4. Вкладка **Поля** — отметьте галочками все нужные поля (НомерДоговора, Автомобиль, ИтоговаяСумма и т.д.).
5. Нажмите **Закрыть и сформировать** или **ОК**, затем **Сформировать**.

Без выбора клиента отчёт **всегда будет пустым** — это нормальное поведение старого запроса.

## Настройка СКД в конфигураторе (обязательно!)

Если отчёт пустой даже с параметрами — почти наверняка не настроена схема.

### Шаг 1. Откройте схему

**Отчёты** → ваш отчёт → **Основная схема компоновки данных** → открыть.

### Шаг 2. Набор данных

- **Наборы данных** → **Добавить** → **Запрос**.
- Имя: `ОсновнойНабор`.
- Вставьте текст запроса из `.txt` файла.
- **Запрос** → **Конструктор запроса** → **ОК** (проверка, что запрос без ошибок).

### Шаг 3. Параметры (для отчётов 2 и 3)

Вкладка **Параметры** → **Добавить**:

**Для «История клиента»:**
| Имя | Тип | Заголовок |
|---|---|---|
| Клиент | СправочникСсылка.Клиенты | Клиент |

Связь: параметр `Клиент` → параметр запроса `&Клиент`.

**Для «Доходы по аренде»:**
| Имя | Тип | Выражение (значение по умолчанию) |
|---|---|---|
| ДатаНачала | Дата | `ДАТАВРЕМЯ(2026, 1, 1)` |
| ДатаОкончания | Дата | `ДАТАВРЕМЯ(2026, 12, 31, 23, 59, 59)` |

> Ваши документы от 19.05.2026 — период должен их включать!

### Шаг 4. Структура отчёта (САМОЕ ВАЖНОЕ!)

Вкладка **Настройки** → в дереве слева:

1. ПКМ на **Отчёт** → **Добавить** → **Детальные записи**.
2. Справа на вкладке **Поля** — перетащите или отметьте галочками **все поля** из набора данных.

Без «Детальных записей» отчёт формируется **пустым**.

### Шаг 5. Ресурсы (для итогов)

Вкладка **Ресурсы** → отметьте поля с суммированием:
- `ИтоговаяСумма` → Сумма
- `КоличествоСуток` → Сумма
- `КоличествоАренд` → Сумма

### Шаг 6. Сохранить и обновить БД

Сохраните схему → **Конфигурация** → **Обновить конфигурацию базы данных**.

## Проверка запроса вручную

В **Консоли запросов** (или конструкторе) выполните упрощённый запрос:

```sql
ВЫБРАТЬ
    Договоры.Ссылка,
    Договоры.Клиент.Наименование,
    Договоры.Автомобиль.Наименование
ИЗ
    Документ.ДоговАренды КАК Договоры
ГДЕ
    Договоры.Проведен
```

- **Есть строки** → данные в базе есть, проблема в настройке СКД или параметрах.
- **Нет строк** → проведите хотя бы один договор аренды.

---

## Быстрый тест: отчёт «Автопарк»

Этот отчёт **без параметров**. Если он тоже пустой — точно не настроена структура СКД (шаг 4 выше).

Должен показать все автомобили из справочника, даже без договоров.
