// Отчёт 2: Доходы по аренде за период
// Имя отчёта: ОтчетДоходыПоАренде
//
// Параметры СКД (вкладка "Параметры"):
//   ДатаНачала    — Дата, по умолчанию: ДАТАВРЕМЯ(2026, 1, 1)
//   ДатаОкончания — Дата, по умолчанию: ДАТАВРЕМЯ(2026, 12, 31, 23, 59, 59)

ВЫБРАТЬ
    ФактПроката.Ссылка КАК НомерЗакрытия,
    ФактПроката.Дата КАК Дата,
    Договоры.Автомобиль.Наименование КАК Автомобиль,
    Договоры.Клиент.Наименование КАК Клиент,
    ФактПроката.ДатаВозврата КАК ДатаВозврата,
    ФактПроката.КоличествоСуток КАК КоличествоСуток,
    ФактПроката.ЦенаЗаСутки КАК ЦенаЗаСутки,
    ФактПроката.ДопРасходы КАК ДопРасходы,
    ФактПроката.ИтоговаяСумма КАК ИтоговаяСумма
ИЗ
    Документ.ФактПроката КАК ФактПроката
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ДоговАренды КАК Договоры
        ПО ФактПроката.Договор = Договоры.Ссылка
ГДЕ
    ФактПроката.Проведен
    И ФактПроката.Дата >= &ДатаНачала
    И ФактПроката.Дата <= &ДатаОкончания

УПОРЯДОЧИТЬ ПО
    Дата
